# Earlier Cece workspace

These files were originally outside the old Git checkout. They have been
preserved here so the earlier design and test work is not lost.

- `Otto_PCB_Prototype/` contains the earlier KiCad designs, schematic,
  routing attempts, reports and related backup. They are engineering drafts
  and are not verified for manufacturing.
- `freecad_cece*/`, `cece_ankle_v2/` and `cece_otto*_prototype/`
  contain early FreeCAD studies, exported parts and reports.
- `Cece_Prototype_Plate/` and `Otto_Simple_Print/` preserve earlier print
  preparation; they do not establish that the parts fit or walk.
- `otto_joint_review/`, `otto_*simulation/`, `out/` and the accompanying
  scripts contain earlier kinematic, contact, drive and design experiments.
- `adafruit_4741_ref/`, `piicodev_servo_ref/` and `otto_reference/`
  preserve relevant third-party references and their available notices.

These are historical files. Some early scripts reference their old workspace
layout or dependencies, so do not assume that each one runs unchanged.
Use [the current simulation guide](../../experiments/cece/START_HERE.md)
for the actively maintained workflow.
