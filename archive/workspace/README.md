# Earlier Cece workspace

These files were originally outside the old Git checkout. They have been
preserved here so the earlier design and test work is not lost.

Remaining folders contain earlier Cece CAD, print studies, component CAD
references and analysis. Legacy reference-robot folders have been removed.
Use the current Cece sources named in the repository AGENTS.md; archived
studies are not active print inputs.

These are historical files. Some early scripts reference their old workspace
layout or dependencies, so do not assume that each one runs unchanged.
Use [the current simulation guide](../../experiments/cece/START_HERE.md)
for the actively maintained workflow.
